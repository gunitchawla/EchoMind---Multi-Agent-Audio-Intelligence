### 🔮 The Vision

Audio Intelligence Security simulates a highly advanced **AI control center**. Leveraging cutting-edge audio processing heuristics, it identifies threats like aggressive shouts or breaking glass in real-time. Whether it's visualization of geographical sensors or deep-diving into why a risk was flagged, the platform bridges the gap between deep AI models and human-centric security monitoring.

<br/>

## ✨ Key Features

| Feature | Description |
| :--- | :--- |
| **🎯 Real-Time Detection** | Live dashboard monitoring of audio streams for anomalies using advanced acoustic metrics. |
| **🧠 Explainable AI (XAI)** | Transparent AI decision-making. Dive into feature importance and detailed trust scores. |
| **🗺️ Sensor Map** | Interactive, geographical UI of your smart city's deployed audio sensors and active threats. |
| **⚙️ Model Training** | Fine-tune your AI with built-in interfaces to configure Random Forests and Neural Networks. |
| **🚨 Auto-Response** | Automated execution of defense playbooks when critical audio thresholds are breached. |

## 🚀 Getting Started

Provide a robust setup for your local security environment.

### 1️⃣ Prerequisites

Ensure you have the following installed to run the control center:
- **Node.js** (v20+ recommended)
- **PNPM** package manager
- **PostgreSQL** database instance

### 2️⃣ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/gunitchawla/audio_intelligence_security.git
cd audio_intelligence_security

# Install dependencies
pnpm install

# Push the schema to your database
pnpm run db:push
```

*(Note: Create a `.env` file in the root based on `.env.example` to supply `DATABASE_URL` before pushing the DB)*

### 3️⃣ Launch the Control Center

```bash
# Start the development server
pnpm run dev
```

> **🟢 System Online**: The dashboard is now accessible at `http://localhost:5000`.
